# Generate or port Shem

Start with spec/COGNIZER.sudo.md, schemas, fixtures/operational-cases.json and the
traceability map. Implement the same bounded configuration, adapter, invocation
and recovery contracts in PowerShell, Perl, C#, VB or another available runtime.
Consume the host's public worker APIs and delivered Harness schemas; do not copy
JavaScript memory validators or create a parallel storage format.

Run each retained fault vector, both work queues and the full transport matrix
against exactly the same published upstream bytes. Differentially compare safe
states, request identities, receipts, UTF-8 hashes and refusal codes. Compare
meanings of model outputs separately. Declare your runtime/dependencies and exact
manifest identity, implemented operations and unimplemented/untested scope.

The parity gate detects inventory/hash drift and, with --base REF, requires source,
SudoLang and fixture changes together. It cannot prove semantic equivalence.
Review the source/specification correspondence before explicitly recording the
manifest with `node tools/parity.mjs --record`. Changes to tests/docs/dependencies
also update the manifest in the same commit. No alternate-language implementation
or complete portability certification ships with this candidate.
